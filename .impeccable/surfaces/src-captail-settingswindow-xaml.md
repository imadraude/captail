# Captail application UI

## Scope and mode

Operate. Applies to the main dashboard, settings, replay player/editor, audio routing, and transient status surfaces.

## Audience and job

Windows players need to confirm capture health, save the recent moment immediately, and configure recording without decoding implementation details. Preserve all behavior, localization, automation names, and keyboard workflows.

## Chosen direction

An operational flight-strip board translated into a compact native Windows capture console. Replays and settings read as ordered strips; recording health is the fixed status rail; the save action is the single high-salience control.

## Direction contract

THESIS: A calm mission board for preserving the last moment; reject the generic stack of floating gamer cards.

OWN-WORLD: Abyss navy ground, slate strips, warm white type, signal coral action, ice-blue navigation; squared 4–10 px corners, fine rules, tabbed status markers, mono telemetry.

STORY: Confirm capture health, understand source and capacity, save instantly, then inspect recent replays or enter task-grouped settings.

FIRST VIEWPORT: A thin title rail, full-width status strip, one dominant save control with time/hotkey, a compact telemetry row, then replay strips. Settings keep a persistent unsaved rail.

FORM: Flight-strip operations board, sixth grounded direction, seed 9e002182. Signature interaction: status markers and action strips change state without layout shift.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
