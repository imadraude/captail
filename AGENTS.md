# Captail Agent Guidelines

## Мова спілкування

- Мова взаємодії з користувачем — виключно українська.

## Контекстуальне семантичне підняття версії та релізи

Коли користувач запитує реліз або коли технічні завдання/фікси готові до випуску, обов'язково виконувати реліз із контекстуальним семантичним підвищенням версії (SemVer).

### 1. Визначення нової версії (Semantic Versioning)

Аналізувати контекст і характер накопичених змін відносно попереднього тегу:

- **Patch (`0.x.Y` → `0.x.(Y+1)`)**: сумісні виправлення багів, візуальні/UI-полірування, мінорні правки стабільності.
- **Minor (`0.X.y` → `0.(X+1).0`)**: нові функції, користувацькі можливості, суттєві поліпшення існуючих робочих процесів.
- **Major (`X.y.z` → `(X+1).0.0`)**: несумісні або фундаментальні зміни архітектури/поведінки.

### 2. Обов'язковий чекліст релізу

Дотримуватися протоколу з `docs/RELEASING.md`:

1. **Підвищення версії в проекті**:
   - `src/Captail/Captail.csproj` (`<Version>X.Y.Z</Version>`).
2. **Оновлення списку змін**:
   - `CHANGELOG.md`: перенести/додати датовану секцію `## [X.Y.Z] - YYYY-MM-DD` із чітким описом впливу на користувача за категоріями (`Fixed`, `Added`, `Improved` згідно з `docs/RELEASE_NOTES.md`).
3. **Оновлення документації та сайту**:
   - `README.md`: оновити поточну версію прев'ю та секцію «What's new in Captail X.Y.Z?».
   - `site/index.html`: оновити `softwareVersion`, fallback-посилання на завантаження (.exe та .zip) і текстовий статус.
   - `site/script.js`: оновити рядок fallback-статусу (`V0.X.Y`).
4. **Валідація метаданих**:
   - Запустити перевірку: `pwsh -File tools/TestReleaseMetadata.ps1`.
   - За потреби перевірити генерацію release notes: `.\tools\New-ReleaseNotes.ps1 -Version X.Y.Z -PreviousTag vPREV`.
5. **Пуш і запуск GitHub Actions**:
   - Зробити коміт підготовки релізу: `release: prepare X.Y.Z`.
   - Запушити зміни в `origin main`.
   - Запустити релізний workflow через GitHub CLI:
     ```powershell
     gh workflow run release.yml --repo imadraude/captail --ref main -f version=X.Y.Z -f prerelease=true
     ```
   - Переконатися, що запуск workflow успішно створено (`gh run view ... --repo imadraude/captail`).
